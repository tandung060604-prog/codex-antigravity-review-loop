# v0.2 — Structured protocol và model routing

## Phạm vi đã triển khai

- JSON Schema bắt buộc cho kết quả mỗi vòng AGY.
- `stream-json` để lấy structured result, conversation ID, duration và usage.
- Helper một vòng dùng argument list an toàn, không ghép shell command.
- Summary metrics mặc định; raw event log chỉ bật khi người dùng yêu cầu.
- Router bốn lớp với trần 2/3/4/5 vòng.
- Gemini Flash Medium/High được pin theo lớp; Gemini Pro cần xác nhận.
- Ba Codex profile và ba custom reviewer mẫu.

## Một vòng hoạt động thế nào

```text
acceptance contract
        ↓
temporary prompt file
        ↓
agy_round.py → AGY stream-json + schema
        ↓
compact summary + usage
        ↓
Codex kiểm tra actual diff + tests
        ↓
accept hoặc correction delta
```

Helper không chạy loop tự động. Codex quyết định sau mỗi round dựa trên diff/test thật; nhờ vậy permission, blocker và scope drift luôn có điểm dừng.

## Lệnh helper

Người dùng thông thường chỉ cần gọi `$agy-review-loop`. Khi debug protocol:

```powershell
python skills\agy-review-loop\scripts\agy_round.py `
  --repo C:\path\to\repo `
  --task-id AUTH-142 `
  --round 1 `
  --class standard `
  --prompt-file C:\path\to\prompt.txt
```

Không truyền `--conversation` tùy ý. Helper chỉ chấp nhận conversation ID đã xuất hiện trong summary của task đó. Không truyền `--approve-pro` nếu người dùng chưa xác nhận Gemini Pro.

## Dữ liệu được lưu

`summary.json` chỉ lưu metadata cần cho routing/evaluation: class, model, trần vòng, conversation ID, trạng thái protocol, thời gian, usage, structured output và warning. Mỗi round được ghi `review_outcome: PENDING_CODEX_REVIEW` để nhắc rằng AGY `DONE` chưa phải Codex acceptance. Prompt không được lưu. Raw event có thể chứa nội dung nhạy cảm nên mặc định tắt.

AGY usage không bao gồm token của Codex. Không tính dollar cost trong code vì giá và subscription allowance có thể thay đổi; hãy đối chiếu số token đo được với bảng giá chính thức tại thời điểm phân tích.
