# v0.2 — Structured protocol và model routing

## Phạm vi đã triển khai

- JSON Schema bắt buộc cho kết quả mỗi vòng AGY.
- `stream-json` để lấy structured result, conversation ID, duration và usage.
- Helper một vòng dùng argument list an toàn, không ghép shell command.
- Summary metrics mặc định; raw event log chỉ bật khi người dùng yêu cầu.
- Host watchdog mặc định bám `--print-timeout` của AGY + 30 giây, kèm heartbeat 30 giây.
- Router bốn lớp với trần 2/3/4/5 vòng.
- Gemini Flash Medium/High được pin theo lớp; Gemini Pro cần xác nhận.
- Ba Codex profile và ba custom reviewer mẫu.

## Một vòng hoạt động thế nào

```text
acceptance contract
        ↓
temporary prompt file
        ↓
agy_round.py → AGY stream-json + schema
        ↓
compact summary + usage
        ↓
Codex kiểm tra actual diff + tests
        ↓
accept hoặc correction delta
```

Helper không chạy loop tự động. Codex quyết định sau mỗi round dựa trên diff/test thật; nhờ vậy permission, blocker và scope drift luôn có điểm dừng.

Nếu watchdog của host hết hạn, helper dừng tiến trình AGY con và ghi `failure.kind: TIMEOUT`. Đây là điểm dừng an toàn; không tự động tiêu quota cho round kế tiếp.

## Lệnh helper

Người dùng thông thường chỉ cần mô tả task; Codex có thể tự chọn skill. Gọi `$agy-review-loop` khi muốn ép sử dụng. Khi debug protocol:

```powershell
python skills\agy-review-loop\scripts\agy_round.py `
  --repo C:\path\to\repo `
  --task-id AUTH-142 `
  --round 1 `
  --class standard `
  --prompt-file C:\path\to\prompt.txt
```

Không truyền `--conversation` tùy ý. Helper chỉ chấp nhận conversation ID đã xuất hiện trong summary của task đó. Không truyền `--approve-pro` nếu người dùng chưa xác nhận Gemini Pro.

Fresh round luôn thêm `--new-project`. Không bỏ cờ này chỉ vì event `init.cwd` trông đúng: default CLI project có thể vẫn giữ workspace cũ, khiến `view_file` và `run_command` chạy sai repository. Khi resume một conversation đã xác minh, AGY tự dùng project gắn với conversation đó.

Chế độ print không thể xử lý hộp xin quyền tương tác, vì vậy hãy tạo allow rule hẹp cho đúng các lệnh đọc/kiểm thử cần thiết. `--sandbox` là opt-in; hãy smoke test trước vì Windows AppContainer có thể yêu cầu nâng quyền tương tác cho executable cài ngoài sandbox.

## Dữ liệu được lưu

`summary.json` chỉ lưu metadata cần cho routing/evaluation: class, model, trần vòng, conversation ID, trạng thái protocol, runtime failure, thời gian, usage, structured output và warning. `PERMISSION_BLOCKED` được ghi là lỗi runtime với protocol `NOT_REACHED`, không phải `INVALID`. Mỗi round được ghi `review_outcome: PENDING_CODEX_REVIEW` để nhắc rằng AGY `DONE` chưa phải Codex acceptance. Prompt không được lưu. Raw event có thể chứa nội dung nhạy cảm nên mặc định tắt.

AGY usage không bao gồm token của Codex. Không tính dollar cost trong code vì giá và subscription allowance có thể thay đổi; hãy đối chiếu số token đo được với bảng giá chính thức tại thời điểm phân tích.
