# Frontend motion example

Copy this into Codex from the target web-project directory:

```text
$agy-review-loop

In the current localhost project, add restrained, accessible motion to the existing interface.

Acceptance criteria:
- section entrance and scroll reveal;
- staggered card/list entry;
- subtle hover and keyboard-focus motion for interactive blocks;
- responsive behavior on desktop and mobile;
- prefers-reduced-motion support;
- no broken content, interactions, or console errors;
- verify the running localhost page, lint, tests, and build.

Inspect the existing stack and dependencies first. Reuse what is already installed; do not rewrite the app or add a motion library unless necessary. Do not commit, push, deploy, or modify unrelated files.
```
